# 10. 그래픽 에셋 조달 권고 — 구매 · AI 생성 · 발주 (2026-09-04)

전제(docs/02 v2): 인게임 = 픽셀(16px 격자, 요괴 32×32/16×16, 뷰포트 640×360), 대화·도감 = 1024×1024 일러스트. 규격은 `art_assets.csv`(키·프레임·애니메이션 구간)가 게임에 꽂아 주고, 웹 Asset Studio(`python tools/art/studio/server.py`)에서 교체·비교한다.
**필요량 (지금 자리표시로 돌아가는 것)**: 하숙생 10·뜨내기 12·적 11·NPC 5 스프라이트(요괴 1명 = idle 4 / walk 6 / work 4 / 감정 2×2 = 18프레임), 방 8칸 그림(64×48), 구역 배경 10(하늘·원경·바닥 띠), 소품 5(채집물·텃밭·문·물·장꾼), UI 9-patch 3, 일러스트 15(요괴 10 + 가택신·NPC 5).

## 1. 무엇을 사고, 무엇을 만들까 (권고 분담)

| 항목 | 권고 | 이유 |
|---|---|---|
| 구역 배경(하늘·원경·바닥 타일), 소품, 가구 | **에셋팩 구매 + 팔레트 통일** | 범용 픽셀 배경·타일은 팩 품질이 좋고 값이 싸다. `tools/art/palette_quantize.py` 로 공통 팔레트에 맞춘다 |
| 요괴·NPC 스프라이트(애니메이션) | **AI 초안 + 사람 후보정, 핵심 6~8명은 외주** | 한국 요괴는 팩이 없다. 애니메이션 일관성은 AI 가 약하므로 idle/walk 만 AI, 감정·work 는 손보정 |
| 도감·대화 일러스트 1024 | **AI 생성 + 후보정** | 정적 일러스트는 AI 강점. 스타일 고정 샘플 3장을 먼저 만들고 그 레퍼런스로 나머지 |
| UI 9-patch·아이콘 | **직접 제작(Aseprite) 또는 UI 팩** | 양이 적고 팔레트 종속 |
| 스토어 캡슐·키 아트 | **사람(일러스트레이터)** | 대표 이미지는 AI 표기 부담과 품질 리스크 |

## 2. 구매 후보 (2026-09 기준 — 가격·라이선스는 결제 전 반드시 재확인)

검색어: itch.io `pixel art side view house interior`, `pixel background parallax forest`, `16x16 tileset asian`, `korean pixel`. 아래는 이 게임 규격(사이드뷰·16px)에 맞는 **카테고리와 대표 판매처**이며, 특정 팩의 현재 가격·약관은 바뀔 수 있어 링크는 적지 않는다.

| 용도 | 후보 유형 | 판매처 | 라이선스 확인 포인트 |
|---|---|---|---|
| 뒷산·개울·마당 원경/하늘 | 사이드스크롤 숲·산 패럴랙스 배경 팩 (16px, 3~5 레이어) | itch.io (Free/Pay-what-you-want 다수), Unity Asset Store, GameDev Market | 상업 이용·재배포 금지 조건, 크레딧 표기 요구 여부 |
| 마계(잿빛 들·늪·문서고) | 던전/유령 숲 계열 배경·타일 | itch.io, GameDev Market | 어두운 톤은 팔레트 재양자화가 잘 맞는다 |
| 방 내부 64×48 | 실내 가구·벽지 타일셋(일본풍 다다미·목조 실내가 가장 가깝다) | itch.io, Craftpix(구독), Unity Asset Store | 한옥풍은 거의 없다 — 목조 실내 팩 + 창호·온돌 소품은 직접 |
| 소품(채집물·농작물·물) | 농장/채집 아이콘·작물 성장 단계 시트 | Sunnyside/Sprout Lands 계열(itch.io), Kenney(CC0) | 톱다운 팩은 작물 단계·아이콘만 재사용 가능 |
| UI 9-patch·커서·아이콘 | 픽셀 UI 팩 | Kenney(CC0), itch.io | CC0 는 표기 불필요 |
| 폰트 | Galmuri(OFL, 한글 픽셀) — 이미 되돌린 이력 있음(사용자 결정 필요) | GitHub | OFL |

Kenney(kenney.nl)는 CC0라 안전하지만 사이드뷰 요괴 세계관과 톤이 다르므로 UI·아이콘·소품용으로만.

## 3. AI 생성 워크플로 권고

### 3.1 픽셀 스프라이트 (요괴·NPC·적)
1. **PixelLab** (pixellab.ai, 유료 구독): 텍스트/레퍼런스 → 캐릭터 시트 + **걷기·idle 애니메이션 자동 생성**. 32×32·4방향/사이드 지원. 상업 이용 약관 확인 후 사용. 이 게임 프레임 표준(idle 4 / walk 6)에 가장 가깝다.
2. **Retro Diffusion** (Aseprite 확장 또는 웹, 유료 크레딧): 16~64px 픽셀 생성·애니메이션 초안. 팔레트 지정 가능.
3. 로컬: Stable Diffusion(SDXL) + 픽셀 LoRA → `palette_quantize.py` 로 팔레트 맞춤 → Aseprite 에서 프레임 정리. 무료지만 일관성 관리 비용이 크다.
- 절차: 컨셉(docs/06 실루엣 키워드) → 정지 1장 확정 → 애니메이션 생성 → 시트로 합치기(가로 배열, 프레임 순서 idle→walk→work→감정) → Asset Studio 스프라이트 탭에서 재생 확인 → `art_assets.csv` 행(frame 32×32, anims) 저장.
- AI 산출물은 `docs/asset_licenses.md` 에 "AI 생성 예" 로 기록(스토어 공개 요구).

### 3.2 일러스트 (도감·대화 1024)
- **Midjourney**(유료 플랜 상업 이용) 또는 **NovelAI**(애니메이션 톤) 또는 SDXL/FLUX 로컬. 레퍼런스 이미지 입력(스타일 고정 샘플 3장)이 되는 툴을 고른다.
- 절차: 팔레트·조명 방향·"펠트/손그림 질감" 프롬프트 고정 → 요괴별 3~4장 생성 → 콘택트 시트 비교 → 후보정(눈·손 오류) → `tools/art/portrait_pipeline.py`(예정) 로 1024 리사이즈·팔레트 근사 → `illust.<id>` 행.
- 캐릭터 일관성: 같은 요괴의 표정 변형은 같은 시드/레퍼런스로.

### 3.3 배경·타일
- 배경은 AI 보다 **팩 구매 + 재양자화**가 빠르고 일관되다. AI 는 마계 지역의 하늘·원경(패럴랙스 레이어) 컨셉 정도.

## 4. 외주 발주서에 넣을 것 (핵심 요괴 6~8명)
규격(32×32, 발이 아래 중앙), 프레임 표준(idle 4 / walk 6 / work 4 / 감정 2×2), 시트 배열(가로 한 줄, 순서 고정), 팔레트 파일(`data/palette.hex`), 실루엣 키워드(docs/06), 조명 방향(좌상), 납품 검수 = `tools/art/validate_assets.py` 통과 + Asset Studio 재생 확인. 1명당 상한 예산은 사용자 결정.

## 5. 예산 초안 (사용자 결정 — 수치는 상한 감각용)
- 배경·타일·UI 팩: 5~10만 원
- PixelLab 또는 Retro Diffusion 1~2개월: 5~10만 원
- 일러스트 AI 구독 1~2개월: 5~10만 원
- Aseprite: 약 3만 원
- 핵심 요괴 외주(선택): 1명당 10~30만 원 × 6~8

## 6. 이번에 만든 툴로 할 수 있는 것
- `python tools/art/studio/server.py` → 브라우저에서 에셋 업로드(라이선스 기록 자동), 스프라이트 시트 재생·프레임 규격 확인, 하숙집 단면·마당·뒷산·탐험지 화면에 실제 배치해 A/B 비교, 매니페스트 저장(빌드 자동 실행) → 게임 재실행 시 반영.
- 규격 검사는 서버의 '검증' 버튼(validate_assets.py) 으로.
