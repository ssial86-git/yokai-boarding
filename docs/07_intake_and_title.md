# 07. 입주 심사 메커니즘 + 프로젝트 가제 후보

작성일: 2026-09-03
전제(2026-09-03 개정): 안 B 「대차대조표의 왕」 확정판(05 문서 7절) 세계관. 심사 UI의 의인화는 문신(문돌이), 정보 보조는 구미호(소문 수집).

---

## 1. 입주 심사 — 설계 목표

1. 경영 축의 핵심 의사결정 지점(저녁 페이즈)을 매일 1회 이하로 만든다. 심사는 잦으면 루틴이 되고, 드물면 이벤트가 된다 — **2~4일에 1회** 빈도로 조정.
2. "받을까 말까"가 항상 트레이드오프이게 한다: 방·식량은 유한, 요괴는 능력과 리스크를 함께 들고 온다.
3. 안 B의 서사 규칙(말소 집행 중 탈출한 요괴 = 등록 정보가 지워져 있음)을 심사의 불확실성으로 그대로 사용한다.

## 2. 심사 플로우 (저녁 페이즈)

```
1. 방문   문 두드리는 소리 → 문돌이가 방문자 정보 카드를 물어다 줌
2. 정보   카드에 보이는 것: 외형, 첫마디, 문돌이의 감(액운 냄새 0~3),
          [대문 레벨만큼] 추가 공개: 능력 힌트, 소문(구미호 보유 시 정확도↑)
          말소 미수 요괴는 카드가 비어 있음 — 최고 리스크이자 최고 서사 보상
3. 결정   받기 / 하룻밤만(관찰 기회, 방 1개 점유) / 거절
4. 결과   받기: 빈 방 배정, 다음 날부터 배치 가능
          거절: 평판 소폭 하락 가능성(정당한 거절은 무해 — 액운 3 요괴 거절 등)
          하룻밤만: 다음 날 아침 추가 정보 1개 공개 후 재결정
```

## 3. 리스크 테이블

| 방문자 유형 | 비율(초안) | 결과 |
|---|---|---|
| 뜨내기 손님 | 60% | `guest_species.csv` 풀에서 등장. 단기 체류·하숙비·명부 기록. 승격 조건 충족 시 장기 계약 제안 가능(→ 하숙생, Tier 2) |
| 말소 미수 '빈 카드' | 15% | 달갤형: 등록 정보가 지워져 심사 정보 없음. 대부분 피해자(큰 서사 보상), 드물게 아래 첩자 |
| 회수 집행관 첩자 | 10% | 실적에 쫓겨 위장 잠입, 3~5일 내 사보타주(하숙부 기록 훼손, 결계 약화). 단서: 밤 행동 이상 — 어둑이 보유 시 감지 확률↑. 사연을 들어주면 전향 가능 |
| 사고뭉치 | 10% | 악의 없는 대형 사고(불가사리가 숟가락을 다 먹는 등). 시설로 관리 가능 |
| 귀인 | 5% | 위장한 희귀 요괴/가택신. 후하게 대접했으면 큰 보상 (전래동화 '나그네 시험' 구조) |

첩자도 소멸시키는 게 아니라 **사연을 들어주면 전향 가능** — 처형 없는 디자인으로 톤 유지. 전향한 집행관은 후일 마계 사정에 밝은 하숙생이 된다.

## 4. 시스템 연동

- **대문 레벨(문돌이)** = 심사 정보량. 증축 동기와 직결.
- **평판** = 유입 요괴의 질·빈도. 정착 완료 요괴 수, 사건 처리, 거절 매너가 반영.
- **결계** = 침공 방어. 첩자 사보타주와 침공 이벤트의 카운터. 등불(어둑이)·부적·가택신 레벨로 상승.
- **데이터 구조**: `visitors.csv`(유형, 가중치, 등장 조건), `guest_species.csv`(뜨내기 종족 풀 — 06 문서 4절), `rumors.csv`(소문 텍스트 풀), 심사 결과·명부는 세이브의 이벤트 로그에 기록.
- **슬라이스 범위**: 유형은 평범/말소 미수(달갤 고정 이벤트)/사고뭉치 3종만, 첩자·귀인은 Tier 2.

## 5. 프로젝트 가제 후보

상표·스팀 중복 검사는 하지 않은 순수 후보다. 확정 전 스팀/상표 검색 필요.

| 가제 | 결 | 비고 |
|---|---|---|
| **문턱 너머 하숙집** | 서정 | "그 집 문턱만 넘으면 산다"는 소문을 그대로 제목화 |
| **달빛 하숙** | 짧고 부드러움 | 밤에 도착하는 손님들, 부르기 쉬움 |
| **요괴네 하숙집** | 직관 | 장르·소재가 제목에서 즉시 전달 |
| **어서 오세요, 결계 하숙집** | 라이트노벨 결 | 긱 톤 강조, 해외 로컬라이즈 시 길어짐 |
| **Mothold** / **문턱(Moonteok)** | 영문 병기용 | 해외 스토어용 짧은 이름은 별도 고민 필요 |

작업용 저장소 이름 권장: `moonlit-boarding` 또는 `yokai-boarding` (가제 확정 전 중립 슬러그).

## 6. 남은 미정 항목

- 평판·결계 수치 모델 (경제 시뮬레이터 구축 시 함께)
