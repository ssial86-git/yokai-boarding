# 01. P1 「하루의 재미」 스코프 v3

작성일: 2026-09-03 (v2 '하숙집 관리 슬라이스'를 08 마스터 디자인 v2 기준으로 전면 개정)
상위 문서: `08_master_design.md` (큰 틀·경험 곡선·분량), 00·05~07 (컨셉·서사·로스터·심사)
P1의 유일한 목적: **"오늘 하루가 재미있는가"** — 경험 곡선의 0~1시간 구간을 완성하고 검증한다.

---

## 1. P1 게이트 (08 문서 7절)

테스터 5명 중 3명 이상이 "오늘 할 일이 밀려서 즐거웠다"는 취지로 말하고, 내장 로그상 하루(실시간 12~15분)에 **서로 다른 활동 4개 이상**을 혼합할 것. 실패 시 콘텐츠 추가가 아니라 사슬(원칙 3)·케이던스(원칙 6) 수정으로 대응.

## 2. P1 시스템 스코프

### 2.1 새로 만드는 것 (동사 구현)

| 동사 | 스펙 | 비고 |
|---|---|---|
| **걷기·달리기** | 좌우 이동 + 사다리·단차 오르내림 + 문 통과(하숙집↔마당↔뒷산↔우물), 달리기는 스태미너 소모 | 정밀 점프 없음. 수치는 tuning.csv |
| **채집** | 뒷산: 나물·버섯·나뭇가지·돌 채집 포인트(일일 리스폰, 절기·음기별 풀), 도끼·곡괭이 상호작용 | 재료 14종 |
| **텃밭 농사** | 밭 6칸→12칸 확장, 괭이질→파종→물주기→수확, 성장 3~5일, 이승 작물 5 + 마계 작물 2(음기 짙은 날 성장 가속) | 가호 접붙이기는 P2 |
| **요리** | 조왕 부엌 가마솥: 레시피 12(티어 1~2), 실시간 조리(1~3분), 결과물은 손님 만족·동료 버프·판매 3중 용도 | 취향 매칭은 단순형(좋아함/보통) |
| **낚시(간이)** | 개울 1지점: 타이밍 바 미니게임(손맛 튜닝 대상 아님 — 관대한 판정), 어종 4 + 고물 2 | 우물 낚시는 P2 |
| **탐험 + 동료 자동 전투** | 잿빛 들(마계 지역 1, 낮 버전만): 채집 8포인트 + 적 2종 + 미니보스 1. 동료 요괴 2 동행, 전투 자동, 플레이어는 이동·회피·부적 투척(쿨다운 1종)·후퇴 | 스태미너·귀환 수단 포함 |
| **실시간 하루·스태미너** | 하루 = 실시간 12분(취침 시 단축), 스태미너 100 예산, 0이 되면 행동 둔화(강제 기절 없음 — 벌 최소화) | 시간대: 아침/낮/저녁/밤은 조명·이벤트 트리거로만 존재, 강제 컷 없음 |

### 2.2 기존 시스템 재정의 (M5 코드 계승)

| 시스템 | 변경 |
|---|---|
| 하숙집·방 그리드 | 로직 유지, 렌더를 '걸어다니는 집'으로 — 플레이어가 방 앞에서 상호작용 |
| 요괴 배치 | **자동화 층으로 재정의**: 배치된 요괴가 요리·청소·텃밭 물주기를 자동 수행(플레이어가 하는 것보다 낮은 효율 → 위임의 트레이드오프). 아침 배치 UI 유지 |
| 심사·손님·명부 | 유지 (저녁 시간대 이벤트로 발생) |
| 사연 이벤트 | 유지 (밤 시간대, 하숙생 3명 × 3막) |
| 세이브 v4 | 실시간 시계·플레이어 위치·탐험지 상태로 확장 (v5) |
| 지표 킷 | **내장 전환**: 동사별 사용 시간·하루 활동 수를 JSONL로 자동 기록 (게이트 판정 데이터) |

### 2.3 P1에서 하지 않는 것

절기 순환(P1은 봄 14일 고정), 명절, 가호, 위장/인간 NPC, 업둥이, 방 꾸미기, 밤 변형 지역, 회색 시장, 챕터 진행(프롤로그만), 뜨내기 승격. — 전부 P2 이후. 단, **데이터 스키마는 P1에서 전부 확정**해 이후 확장이 CSV 행 추가가 되게 한다.

## 4. P1 케이던스 초안 (unlocks.csv의 씨앗)

| 시점 | 해금 |
|---|---|
| 1일차 | 프롤로그, 하숙부 발견, 뚝딱이 입주, 텃밭 3칸 |
| 2일차 | 뒷산 개방, 채집 도구, 첫 레시피 3 |
| 3일차 | 어둑이 방문(밤), 우물 아래 첫 하강 → 잿빛 들 입구 |
| 4~5일차 | 낚시 개방, 달갤 사건(심사 튜토리얼), 부적 제작 |
| 6~8일차 | 잿빛 들 심부(미니보스), 배치 자동화 해금(뚝딱이 호감 2), 텃밭 확장 |
| 9~14일차 | 마계 작물, 레시피 티어 2, 미니보스 재도전(강화), 사연 3막들, 뜨내기 희귀종 첫 등장 |

규칙: **어느 30분을 잘라도 그 안에 '처음 보는 것'이 1개 이상** 있어야 한다. 위 표를 `unlocks.csv`로 옮긴 뒤 시뮬레이터로 검사한다.

## 5. 데이터 스키마 확정 대상 (P1에서 전부)

- 기존 유지: yokai, guest_species, spirits, rooms, visitors, rumors, items, recipes(요리로 확장), dialogue, events, tuning, strings_ko
- 신규: `materials.csv`(이승/마계 축, 절기·음기 조건), `crops.csv`, `fish.csv`, `talismans.csv`, `tools.csv`, `regions.csv`(탐험지·채집 포인트·적 배치), `enemies.csv`, `unlocks.csv`(id, 조건식, 해금 대상, 안내 문구), `chains.csv`(콘텐츠 id, 용도1·2·3 — 3칸이 다 차야 빌드 통과), `metrics_events.csv`(지표 이벤트 정의)
- `chains.csv`는 CI에서 검증: 용도 3칸 미만인 콘텐츠가 있으면 빌드 실패. 재미 원칙 3을 기계로 강제하는 장치.

## 6. 기술 노트 (구현 방향)

- 플레이어: CharacterBody2D + 상호작용 영역(Area2D) + 컨텍스트 프롬프트("E: 캐기"). 이동 수치 tuning.csv.
- 실시간 시계: 기존 Clock autoload을 페이즈 스테이트머신에서 **분 단위 타임라인 + 시간대 트리거**로 교체. 저장 호환을 위해 세이브 v5 마이그레이션 작성.
- 탐험지: regions.csv 기반 씬 조립(채집 포인트·적 스포너를 데이터로 배치). 동료 AI는 '가장 가까운 적 자동 교전 + 플레이어 반경 복귀' 최소 규칙에서 시작.
- 자동화: 기존 Assignment 로직 유지, 산출 계산에 '플레이어 수동 대비 효율 계수'만 추가.
- 밸런스: 경제·스태미너·성장일은 Python 시뮬레이터(14일 자동 플레이)로 초안 → 사람 확정.
