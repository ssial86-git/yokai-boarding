# 02. 아트 소싱 전략 v2 — 픽셀 + 일러스트 혼합

작성일: 2026-09-03 (v1 '픽셀 단일' 개정 — 혼합 아트 결정 반영)

---

## 0. 전제

- **이원화 확정**: 인게임(단면 하숙집·요괴 스프라이트) = 픽셀아트 / 대화·요괴 도감·핵심 연출 = 고해상도 일러스트(레퍼런스의 펠트·손그림 질감 계승).
- 2026년 현재 AI 이미지 생성의 강점은 **정적 일러스트**이고 약점은 **프레임 애니메이션 일관성**이다. 이 분업은 그 강약점과 정확히 맞는다: 일러스트 트랙은 AI 비중을 높게, 픽셀 애니메이션 트랙은 에셋·외주 비중을 높게 가져간다.
- 확정 구조(직접 조작 없음, 파견 자동전투) 덕분에 픽셀 애니메이션 수요 자체가 작다: 요괴 1명당 idle 4 / 걷기 6 / 일하기 4 / 감정 2종이 표준.

## 1. 원칙 (v1 유지 + 추가)

1. 규격 먼저 고정, 아트는 바꿔 끼운다. **타일 격자 16px, 요괴 24×24~32×32, 뷰포트 640×360** (01 문서 8절과 함께 확정 필요). 일러스트는 도감 기준 1024px 정사각 원본 → 인게임 축소 표시.
2. 슬라이스 검증 전에는 아트에 큰돈을 쓰지 않는다.
3. **두 트랙을 잇는 공통 가이드가 최우선 산출물**: 팔레트(32~48색 저채도+온색 포인트), 디자인 언어(둥근 실루엣·큰 눈·짧은 팔다리), 조명 방향. 픽셀과 일러스트가 같은 팔레트·같은 실루엣을 쓰면 톤이 통일된다.
4. 스타일 가이드는 사람이 결정하고, Claude Code는 검증 스크립트로 강제한다.

## 2. 트랙별 소싱

### 트랙 P — 픽셀 (인게임)

| 단계 | 소싱 | 비고 |
|---|---|---|
| 슬라이스 | 실내·가구·캐릭터 에셋팩 + 툴 생성 임시 스프라이트 | v1의 농장 팩 후보는 컨셉 변경으로 폐기. 한옥/일본 여관풍 실내 팩은 드물어 **재조사 필요** — 없으면 범용 실내 팩 + 팔레트 통일로 대체. 요괴 3종은 `gen_placeholder.py` 색 블록+표정으로도 슬라이스 검증 가능 |
| Go 판정 후 | 소품·가구는 AI(Retro Diffusion 16px 모델)+후보정 시험, 요괴 스프라이트는 픽셀 아티스트 외주 | 발주서: 규격+프레임 표준+공통 팔레트+플레이 영상. 달갤(얼굴 회복)·어둑이(또렷해짐)의 단계 변형 명시 |

### 트랙 I — 일러스트 (도감·대화·연출)

| 단계 | 소싱 | 비고 |
|---|---|---|
| 슬라이스 | **AI 생성 + 후보정** 3장 (뚝딱이·어둑이·달갤 도감) | 레퍼런스 3장 + 공통 팔레트로 스타일 고정 샘플을 만들고, 이후 생성은 그 샘플을 레퍼런스로 사용(모델의 이미지 레퍼런스 기능 활용). 캐릭터별 시트(정면 1포즈 + 표정 2)면 충분 — 애니메이션이 없어 일관성 부담이 낮다 |
| Go 판정 후 | 스타일 유지 가능하면 AI+후보정 지속, 아니면 일러스트레이터 외주 | 도감 일러스트는 스토어 캡슐·마케팅 아트로 재사용되므로 최종 품질 기준은 높게. **Steam AI 콘텐츠 공개 정책 대응: 사용 여부·범위를 `docs/asset_licenses.md`에 상시 기록** |

## 3. Claude Code가 맡는 파이프라인 툴 (v1 계승 + 변경)

| 툴 | 기능 | 상태 |
|---|---|---|
| `tools/art/validate_assets.py` | 규격·팔레트·투명도·파일명 검사 (픽셀/일러스트 트랙별 규칙 분리) | v1 계승, 트랙 규칙 추가 |
| `tools/art/palette_quantize.py` | 에셋팩 → 공통 팔레트 매핑 | v1 계승 |
| `tools/art/sheet_slicer.py` | 시트 → SpriteFrames(.tres) 생성 | v1 계승 |
| `tools/art/gen_placeholder.py` | 요괴·방 임시 스프라이트 생성 (색 블록+라벨+표정) | v1 계승, 요괴용 표정 변형 추가 |
| `tools/art/portrait_pipeline.py` | 일러스트 원본 → 리사이즈·팔레트 근사 보정·도감/대화용 크롭 일괄 처리 | **신규** |
| `tools/art/ai_batch.py` | 생성 API 배치 호출 → 콘택트 시트 출력 | v1 계승 (일러스트 트랙에도 사용) |
| Godot 설정 | Nearest·픽셀 스냅·정수 배율 (일러스트 노드만 Linear 필터 예외) | v1 계승 + 예외 추가 |

## 4. 톤 전달 보강 (v1 계승)

팔레트 강제, CanvasModulate 시간대 색조, 등불 PointLight2D(어둑이·결계 연출과 직결), 비 오는 날 창밖 파티클, CC0 환경음(빗소리·화덕 소리). 하숙집 컨셉에서는 **실내의 따뜻한 빛 vs 창밖의 어스름** 대비가 톤의 절반을 만든다 — 전부 코드로 구현 가능한 영역.

## 5. 리스크

| 리스크 | 대응 |
|---|---|
| 픽셀·일러스트 톤 불일치 | 공통 팔레트+실루엣 가이드 선행, 도감 UI에 픽셀 프레임 장식으로 두 스타일을 의도적으로 연결 |
| AI 일러스트 스타일 표류 (장수 늘수록) | 스타일 고정 샘플 세트 유지, 신규 생성마다 콘택트 시트 비교 검수 |
| AI 콘텐츠 스토어 정책·저작권 | 사용 범위 상시 기록, 스토어 제출 전 재검토. 캡슐 아트 등 대표 이미지는 사람 최종 작업 권장 |
| 한옥풍 실내 픽셀 에셋 부재 | 범용 실내 팩+팔레트 통일로 슬라이스 통과 후, 배경 타일만 외주하는 소규모 발주 옵션 |
| 외주 규격 불일치 | 발주서에 규격·프레임·피벗 명시, `validate_assets.py` 검수 (v1 계승) |
