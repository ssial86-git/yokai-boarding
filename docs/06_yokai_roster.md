# 06. 요괴 로스터 — 2계층 구조 (장기 하숙생 + 뜨내기 손님)

작성일: 2026-09-03
전제(2026-09-03 개정): 서사 **안 B 「대차대조표의 왕」 확정판**(05 문서 7절) 기준. 규칙 요약 — 폭군은 요괴를 '쓸모'로 장부에 기록하고 실적 미달이면 말소(이름·얼굴·전승 삭제)하며, 플레이어는 사연을 들어 **하숙부**에 기록해 요괴를 말소로부터 지킨다.
이름은 전부 가칭이며, 각 항목은 `yokai.csv` / `spirits.csv`의 행이 될 수 있게 구조화했다.

## 0. 로스터 2계층 구조 (2026-09-03 확정)

수집의 넓이와 서사의 깊이는 한 계층으로 다 담을 수 없다(비용상 불가). 두 계층으로 분리한다.

| | **장기 하숙생 (Named)** | **뜨내기 손님 (Guest)** |
|---|---|---|
| 1.0 목표 수량 | **16~20마리** | **30~40종족** (종족 × 성격 × 색상 변형) |
| 콘텐츠 밀도 | 사연 3막 + 전용 일러스트 + 시설·파견 특성 + 개별 하숙비 | 플레이버 1~2줄 + 특이 하숙비 + 스프라이트 1벌 (일러스트·사연 없음) |
| 체류 | 상주 (배치·파견 대상) | 하룻밤~며칠 묵고 떠남 (수익·이벤트 원천) |
| 도감 | **하숙부** — 사연 기록 = 말소 보호 (깊이) | **손님 명부** — 종족 수집 체크리스트, 희귀도 표기 (넓이) |
| 담당 재미 | 관계·서사·배치 퍼즐 | 수집욕, "오늘은 누가 올까", 경제 다양성 |
| 아트 비용/개체 | 높음 (스프라이트+일러스트+단계 변형) | 낮음 (스프라이트 1벌, AI+후보정·외주 물량 처리 가능) |

**승격 흐름**: 뜨내기 중 조건(재방문 횟수, 특정 대접, 평판)을 만족한 요괴에게 **장기 계약을 제안** → 이름과 사연이 열리며 하숙생으로 승격(전용 이벤트). 수집 층이 서사 층의 입구가 된다. 승격 대상 종족은 데이터로 지정(모든 종족이 승격 가능한 건 아님).

**수량 근거(추정, 슬라이스에서 실측 후 확정)**: 하숙생 20마리 = 사연 이벤트 60개(이벤트당 ~20줄, 총 ~1,200줄) + 일러스트 20장 + 스프라이트 20벌 — Claude 초안+사람 퇴고 체제의 상한선 안쪽. 뜨내기 40종은 스프라이트 물량 작업.

## 1. 로스터 설계 원칙 (장기 하숙생)

- 하숙생 1명 = 시설 특성 + 파견 능력 + 하숙비 + 사연 3막(막마다 아버지 단서 0~1개). 4요소가 서로 다른 조합이 되도록 분산.
- 슬라이스(★ 표시 3명)는 경영 축 검증에 필요한 최소 조합: 생산형 + 서비스형 + 리스크형.
- 전승이 있는 요괴는 전승의 핵심 성질을 게임 기능으로 번역한다 (전승 성질 → 기능 번역을 각 항목에 명시).
- 파견 능력치는 4종으로 고정: 힘(전투) / 재주(채집·해체) / 눈(탐색·함정) / 담력(공포 저항). 자동전투 시뮬레이터의 입력이 된다.

## 2. 하숙생 요괴 (6)

### ★ Y01. 뚝딱이 — 애기 도깨비
- **전승 → 기능**: 도깨비방망이(두드리면 물건이 나옴)·씨름 좋아함 → **작업장 생산 특화, 힘 스탯 최고**.
- **성격/외형 키워드**: 자신만만한 꼬마 장사. 둥근 몸에 뿔 하나, 씨름샅바를 늘 매고 다님.
- **시설 특성**: 작업장 배치 시 제작 속도 보너스. 소음 발생 — 옆방 요괴 수면 방해(배치 퍼즐 요소).
- **하숙비**: 돈 대신 **밤새 뚝딱 만든 잡동사니**(랜덤 재료 상자). B안 흡수 사례.
- **사연 3막**: 씨름에서 진 적 없다는 허풍 → 사실 방망이 '생산 할당(공출)'을 거부하다 회수 집행관에게 방망이를 반쯤 뺏기고 도망침 → 방망이 수리(작업장 Lv3 필요)로 자존감 회복. 단서: 방망이에 아버지의 부적 조각.
- **파견**: 힘4 재주2 눈1 담력3.

### ★ Y02. 어둑이 — 어둑시니
- **전승 → 기능**: 어둠 속에서 나타나 관심을 원하며 악의 없는 장난, 올려다보면 커짐(전승 변형) → **밤 시간대 전용 일꾼, 관심(상호작용)을 받을수록 능력 상승**.
- **성격/외형 키워드**: 낯가리는 그림자 뭉치. 눈만 크고 몸은 연기처럼 흐림. 관심받으면 몸집이 커지며 또렷해짐 — **'하숙부 기록 = 존재감' 규칙을 시각으로 보여주는 튜토리얼 캐릭터**.
- **시설 특성**: 등불지기 — 밤 동안 결계(빛) 유지비 절감. 손님이 무서워하면 평판 하락 리스크(호감도로 해소).
- **하숙비**: **그림자 심부름**(밤 사이 다른 방 정리·배달 대행).
- **사연 3막**: 장난이 잦아 미움받을까 전전긍긍 → 사실 공포 실적 평가에서 '무섭지 않음' 판정을 받아 감가상각(말소) 통보를 받고 도망쳐 옴 → "무섭지 않아도 네 자리가 있다"로 하숙부에 기록되며 정체성 확립. 단서: 말소 통보서 뒷면에 적힌 아버지의 탈출 경로 메모.
- **파견**: 힘1 재주2 눈4 담력2 (밤 파견지 보정).

### ★ Y03. 달갤 — 달걀귀신
- **전승 → 기능**: 눈코입 없는 얼굴 → **말소 집행이 절반 진행된 채 탈출한 '말소 미수' 요괴**(등록 정보가 지워져 얼굴을 잃음). 안 B의 핵심 피해 사례이자 입주 심사 리스크의 튜토리얼(07 문서 연동).
- **성격/외형 키워드**: 말 못 하는 매끈한 달걀. 감정은 몸짓과 김서림으로만 표현. 사연을 되찾을 때마다 얼굴 부위가 하나씩 돌아옴 — **진행도가 외형에 그려지는 캐릭터**.
- **시설 특성**: 무표정 접객(?) — 조용한 방 담당. 사연 회복 전에는 특성 미미, 회복할수록 강화.
- **하숙비**: 지불 불가(말소 미수 상태) → 회복 후 소급 지불(감동 포인트).
- **사연 3막**: 전부 파견으로 회수한 '지워진 기록 조각'(찢긴 장부 페이지) 아이템으로 진행 — **탐험 축과 이야기 축의 직결 사례**. 단서: 되찾은 첫 기록에 남은 아버지의 서명 — 말소를 중단시킨 사람이 아버지였다.
- **파견**: 힘1 재주1 눈2 담력4 (공포 면역 — 무서운 게 안 보임).

### Y04. 바리 — 새끼 강철이 (전직 실적 에이스)
- **전승 → 기능**: 강철이(가뭄을 부르는 이무기 이명) → **화덕·건조 시설 특화, 물 시설과 상극**. 마계 재해국의 가뭄 실적 1위였다가 양심 이탈한 전력 때문에 다른 하숙생이 경계 — 관계 이벤트 원천.
- **하숙비**: **비늘 1장**(최고급 제작 재료).
- **사연 3막**: "더는 논밭을 마르게 하고 싶지 않았다"는 이탈 사유 → 재해국 시절 알게 된 **문서고(장부 보관소)의 위치**를 털어놓음 → 챕터 2 개방 열쇠. 단서: 재해국 명부에서 본 아버지의 잠입 기록.
- **파견**: 힘3 재주1 눈2 담력4.

### Y05. 무쇠 — 불가사리
- **전승 → 기능**: 쇠를 먹고 자라는 불가사리 → **고철 재활용 시설, 먹은 만큼 몸집·힘 성장**(장기 육성 캐릭터). 재난(화재) 방어 전승 → 침공 이벤트 방어 보너스.
- **하숙비**: 몸에서 떨어지는 **쇠부스러기**(제작 재료).
- **파견**: 힘5 재주1 눈1 담력3 (성장 시 상승).

### Y06. 아홉 — 수습 구미호
- **전승 → 기능**: 둔갑 수련 중(꼬리 아홉을 아직 못 채움) → **접객·변장 특화, 파견에서 '눈' 최고치**. 슬라이스 이후 서비스 축 확장 담당.
- **하숙비**: **소문 수집**(입주 심사 정보 정확도 상승 — 07 문서 연동).
- **파견**: 힘2 재주3 눈5 담력1.

## 3. 가택신 (3) — 시설 상주 NPC, 하숙생과 구분

| 신 | 전승 | 게임 역할 |
|---|---|---|
| **성주 영감** (성주신) | 집 최고신, 가장 수호 | 결계 시스템의 의인화. 평소엔 대들보에서 졸고 있음. 챕터 진행·증축 허가·아버지 계약의 증인. 튜토리얼 내레이터 |
| **조왕 아주머니** (조왕신) | 부엌·불·재물 | 주방 시설 레벨의 의인화. 요리 = 요괴 컨디션 버프. 하숙비 정산 담당 |
| **문돌이** (문신) | 대문으로 드는 액과 잡귀를 막음 | **입주 심사 UI의 의인화**. 방문 요괴의 정보 카드를 물어다 줌. 심사 정확도 = 대문 레벨 |

증축 확장 시 터주(마당·밭), 업신(곳간 이자), 측신(뒷간 — 개그 담당) 순으로 추가. 슬라이스에는 성주·조왕·문돌이 3신만.

## 4. 뜨내기 손님 — 초기 종족 예시 (슬라이스용 4종)

종족 데이터는 `guest_species.csv` (종족, 희귀도, 플레이버, 하숙비, 승격 가능 여부, 등장 조건). 슬라이스는 아래 4종만.

| 종족 | 희귀도 | 플레이버·하숙비 |
|---|---|---|
| 몽당귀 (몽당연필 요괴) | 흔함 | 하숙비: 낙서 한 장 (장식 아이템) |
| 이불낭 (이불 뒤집어쓴 무언가) | 흔함 | 체크아웃까지 정체 불명. 하숙비: 따뜻한 온기(연료 절약) |
| 우산손 (버려진 우산 요괴) | 보통 | 비 오는 날만 방문. 하숙비: 비 예보 |
| 금줄이 (새끼줄 요괴) | 희귀 | 묵은 방에 액막이 부여. 하숙비: 결계 보너스. **승격 가능** |

## 5. 슬라이스 적용

- 슬라이스 등장: 장기 하숙생 **Y01 뚝딱이, Y02 어둑이, Y03 달갤** + 가택신 3 + 뜨내기 4종(위 표, 명부 기록까지만 — 승격은 Tier 2). 생산·야간 운영·리스크·수집 훅을 모두 커버한다.
- Y04~Y06은 데이터만 만들어 두고(csv 행 + 임시 스프라이트) 슬라이스 이후 투입 — 파이프라인 검증(코드 수정 없는 추가)의 시험 대상으로 사용.
- 아트 발주 단위: 요괴 1명 = 픽셀 스프라이트 1벌(idle 4 / 걷기 6 / 일하기 4 / 감정 2종) + 도감 일러스트 1장. 달갤·어둑이는 상태 변화(얼굴 회복, 또렷해짐) 단계별 변형 필요 — 발주 시 명시.
