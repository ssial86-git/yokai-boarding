# 00. 컨셉 문서 — 요괴 하숙집 (가제)

최종 갱신: 2026-09-03 (레거시 정리 — 폐기된 결정·구 루프 제거. 이력은 git 히스토리 참조)
큰 틀(재미 원칙·경험 곡선·시스템·분량)은 `08_master_design.md`가 상위 문서다.

---

## 1. 한 문장 컨셉

**행방불명된 퇴마사 아버지의 낡은 하숙집을 물려받아, 마계의 폭군을 피해 도망쳐온 요괴들을 받아들이고, 그들과 함께 집을 키우고 마계를 탐험하는 사이드뷰 생활·경영 게임.**

## 2. 설정

- 플레이어는 영문도 모른 채 행방불명된 아버지의 허름한 집을 물려받는다.
- 아버지는 퇴마사였으나 요괴들을 측은히 여겨 배려했고, 그 덕에 요괴들 사이에 명망이 높았다.
- 마계의 폭군 「대차대조표의 왕」을 피해 도망쳐온 요괴들이 그 명망을 따라 하숙집으로 찾아든다.
- 톤: 기괴함이 아니라 귀여움 + 약간의 긱(geek)함.

## 3. 확정 결정 (현행)

| 항목 | 결정 |
|---|---|
| 설계 최우선 팩터 | **플레이어 재미·만족감** (개발 기간은 설계 제약으로 쓰지 않음 — 08 문서 기준) |
| 플랫폼 | PC(Steam) 우선, 프리미엄 판매. 방치형·광고 훅 금지 |
| 조작 | **직접 조작**: 생활(채집·농사·요리·제작·낚시)+탐험까지 직접, **전투는 동료 요괴 자동**(플레이어는 이동·회피·부적 투척·후퇴) |
| 공간 | 걸어다니는 단면 하숙집(방 단위 증축) + 이승(마당·뒷산·개울·마을) + 마계 탐험지. 정밀 플랫포밍 없음 |
| 시간 | 실시간 하루(12~15분) + 스태미너, 4절기 × 28일, 명절 4(정월대보름·단오·백중·동지) |
| 서사 | 「대차대조표의 왕」 — 장부(쓸모) vs 하숙부(사연), 말소로부터 요괴를 지키는 이야기 (05 문서) |
| 세계관 기반 | 가택신 신앙 — 방 증축 = 가택신 깨우기, 성주신 결계 계약 |
| 로스터 | 2계층 — 장기 하숙생(사연 3막, 20) + 뜨내기 손님(종족 수집, 48) + 승격 흐름 (06 문서) |
| 엔진 | Godot 4.7 + GDScript (CLAUDE.md 규약) |
| 아트 | 픽셀(인게임) + 일러스트(대화·도감) 혼합. 품질·손맛의 최종 판단은 개발자 몫 (02 문서) |
| 출시 전략 | 얕은 EA 시작 → 대형 업데이트 확장. 단계 전환은 기간이 아니라 **재미 게이트**(08 문서 7절) |
| 작업 기본값 | 요괴 32×32(소형종 16×16), 뷰포트 640×360, 저장소 `yokai-boarding`, 정식 가제는 스팀 페이지 전 확정 |

## 4. 코어 루프 (08 문서 3절 요약)

아침에 하루를 계획하고(명절·부탁·재료), 낮에는 생활과 탐험에 시간·스태미너를 자유 배분한다 — 하숙집은 배치해 둔 요괴들이 자동으로 굴린다. 저녁에 손님을 심사하고 하숙비가 들어오며, 밤에는 사연을 듣거나 밤 마계로 내려간다. 메타 루프: 전리품·재화 → 증축·시설 → 평판 → 희귀 요괴 유입 → 더 깊은 탐험 → 서사 진전. 목표 층위 3: 오늘 / 이번 절기 / 챕터.

## 5. 콘텐츠 엔진

**콘텐츠 추가 단위 = 요괴 1명 (CSV 행 + 아트 1세트).** 장기 하숙생은 시설 특성·파견 능력·하숙비·사연을 한 묶음으로 갖고, 모든 콘텐츠는 데이터 파일이 진실 공급원이다. 재미 원칙은 데이터로 강제된다: `chains.csv`(모든 콘텐츠 용도 3칸 필수), `unlocks.csv`+시뮬레이터(새로움 없는 30분 금지).
