# 08. 마스터 디자인 v2 — 요괴 하숙집 (재미 최우선 기준)

작성일: 2026-09-03 (v1을 전면 개정)
설계 기준: **플레이어의 재미·만족감이 유일한 1순위 팩터다.** 개발 기간은 설계 제약으로 쓰지 않는다. 그래픽 에셋 품질과 조작 손맛은 사용자(개발자 본인)가 해결하는 숙제로 분리하고, 이 문서는 순수하게 "플레이하는 사람이 언제, 왜 재미있는가"만으로 분량과 구조를 정의한다.
위상: 이 문서가 게임의 큰 틀. 00(컨셉·서사)·05~07(폭군·로스터·심사)은 유지, 01은 이 문서 승인 후 v3로 재작성. M5 코드는 8절 재사용 맵대로 계승.

---

## 1. 진단 — 슬라이스가 심심했던 구조적 이유

1. **동사 부족**: 배치·증축·심사·대화 4개, 전부 '관리'. 내 손으로 하는 일이 없었다.
2. **시간 자율성 부재**: 페이즈 강제 진행이라 "오늘 뭘 먼저 하지"라는 계획의 재미가 없었다.
3. **자원 사슬 1줄**: 시설 가동→돈→증축뿐. 겹치는 시스템이 없어 발견이 없었다.
4. **목표 층위 1층**: 방 늘리기뿐. 오늘/이번 절기/장기 목표가 동시에 굴러가지 않았다.

## 2. 재미 원칙 6

1. **동사 12+**: 걷기, 채집, 괭이질·물주기·수확, 요리, 부적·가구 제작, 낚시, 벌목·채광, 대화·선물, 심사, 배치·지시, 증축·꾸미기, 탐험(+동료 전투 지시·부적 투척).
2. **실시간 하루 + 스태미너**: 하루 = 실시간 12~15분, 스태미너가 예산. 시간 배분은 전부 플레이어 몫. 강제 컷은 취침뿐.
3. **한 행동은 세 갈래 이상으로**: 어디에도 두 번 쓰이지 않는 시스템은 넣지 않는다 (6절 사슬 검증표).
4. **이승/마계 이중 경제**: 나쁜 날씨는 없고 다른 기회의 날씨만 있다. 음기 짙은 날 = 인간 손님 끊김 + 마계 작물·손님·채집 대목.
5. **하숙집 = 자동화 층**: 내가 하던 일을 요괴에게 넘기는 것이 성장. 초반엔 내가 다 하고, 후반엔 하숙집이 나 없이 돈다.
6. **케이던스 보장**: 새로운 것(시스템·지역·요괴·레시피 계열·이야기) 없이 흐르는 실플레이 30분이 존재하지 않게 한다. 해금 일정은 `unlocks.csv`로 데이터화해 관리·검증한다.

## 3. 큰 틀 — 공간·시간·루프 (v1 유지)

- **공간**: 하숙집(걸어다니는 단면, 방 증축)+마당 텃밭 / 뒷산·개울·마을 상점가(이승) / 우물 아래 마계 관문 → 회색 시장·잿빛 들·달무리 늪·문서고 외곽·문서고 심부(마계). 탐험지 총 **7 + 밤 변형**(같은 지역이 밤에는 다른 채집물·다른 위험). 정밀 플랫포밍 없음.
- **시간**: 4절기 × 28일. 명절 4(정월대보름·단오·백중·동지) + **소절기 이벤트 8**(장마 시작, 첫눈, 유성우, 만월 등 — 이틀짜리 미니 이벤트). 날씨 = 이승 날씨 × 음기 지수.
- **하루 루프**: 아침 계획 → 낮 자유 배분(생활/탐험, 하숙집은 요괴가 자동 운영) → 저녁 손님·심사 → 밤 사연 또는 밤 마계 → 취침 정산.
- **목표 층위 3**: 오늘(부탁·재료·손님) / 절기(명절 준비·한정 작물·증축) / 장기(챕터·도감·정착).

## 4. 세부 시스템 (v1 대응표 유지 + 보강)

v1의 Doloc 대응표를 그대로 계승하되, 재미 기준으로 세 가지를 보강한다.

- **가호 접붙이기 확장**: 씨앗뿐 아니라 **요리·부적에도 가호 부여 가능** (하숙생 20명 × 부여 대상 3종 = 조합 실험 공간이 게임 후반의 놀이터). 가호끼리의 시너지 6쌍·간섭 4쌍을 심어 발견의 재미를 만든다.
- **위장(인간 대응) 시스템 승격**: 인간 손님·마을 NPC에게 요괴를 들키지 않기. 소문 게이지, 위장용 가구·요리, 들킬 뻔한 순간의 코미디 이벤트 12종. 이 게임만의 고유 긴장이므로 보조가 아니라 정식 시스템으로.
- **우물 낚시 = 랜덤 박스**: 고물·기억 조각·희귀 재료에 더해 **낮은 확률로 뜨내기 손님이 낚여 올라온다**(전용 연출). 모든 파밍 행위에 이런 1% 급 희귀 이벤트를 최소 1개씩 심는다(도파민 변동성 원칙).

## 5. 플레이어 경험 곡선 — 이 게임이 재미있어야 하는 순간들

분량·해금·서사는 전부 이 곡선을 만족시키기 위해 존재한다. 각 구간의 "느낌"이 검증 기준이다.

| 구간 | 플레이어가 느껴야 하는 것 | 그걸 만드는 장치 |
|---|---|---|
| **0~10분** | "이 집엔 비밀이 있다" | 폐가 도착 → 성주 영감 깨움 → 첫 요괴가 문을 두드림 → 아버지의 하숙부 발견. 10분 안에 입주 1명 + 비밀 1개 |
| **~1시간** | "할 수 있는 게 계속 늘어난다" | 동사 6개 개방(채집·텃밭·요리·심사·대화·증축), 우물 아래 첫 하강. 첫 하숙비, 첫 사연 1막 |
| **1~5시간** | "계획을 세우게 된다" | 절기 캘린더 인지, 첫 명절(동지) 준비, 회색 시장 개방, 첫 승격, 도구 첫 업그레이드. 할 일이 즐겁게 밀리기 시작 |
| **5~15시간** | "하숙집이 내 작품이 된다" | 자동화 전환(요리·채집 위임), 방 꾸미기·손님층 분화, 가호 조합 실험 시작, 챕터 2~3, 위장 시스템의 긴장과 코미디 |
| **15~40시간** | "완성하고 싶다" | 전 지역·밤 변형 개방, 도감 3권 수집욕, 명절 만점 도전, 챕터 4~5, 하숙생 정착 에필로그가 하나씩 완성 |
| **40시간~ (엔드게임)** | "내 하숙집이 살아서 돈다" | 만원 하숙집 자동 운영 관상, 희귀 뜨내기 사냥, 가호 시너지 도감, 진 엔딩 조건 수집, 2회차(선택 분기 반대편) |

## 6. 콘텐츠 분량 — "충분히 재미있는" 기준 (단일 목표)

기간 역산이 아니라 위 경험 곡선을 끊기지 않게 채우는 데 필요한 양으로 정의했다. EA/1.0 구분은 릴리스 전술일 뿐이며 설계 목표는 아래 하나다.

| 항목 | 목표 | 재미 근거 |
|---|---|---|
| 작물 | **32** (이승 18 / 마계 14) + 가호 **24** | 절기당 신작물 3+ 보장, 가호 조합 실험 공간 |
| 재료 | **60** | 지역 7×밤 변형에 고유 재료 배치, 사슬 다층화 |
| 요리 | **72** (티어 4) | 손님 취향×명절×버프×사연 4중 용도를 겹침 없이 |
| 부적 | **30** / 도구 4갈래 × Lv5 | 탐험·생활·방어 빌드 다양성 |
| 가구 | **60** / 방 종류 **14** | 꾸미기·위장·손님층 분화 |
| 탐험지 | **7 + 밤 변형 7** | 15시간까지 새 공간이 마르지 않게 |
| 절기 이벤트 | 명절 4 + 소절기 8 | 28일 절기 내 "달력 보는 재미" 유지 |
| 장기 하숙생 | **20** (사연 3막 + 정착 에필로그) | 1~5시간 구간 1시간당 1명 입주 케이던스, 이후 2~3시간당 1명 |
| 뜨내기 종족 | **48** (희귀도 4단계) | 심사·명부 수집의 가챠적 설렘 유지 |
| 업둥이 | **6** | 목축 축 + 배달 자동화 |
| 인간 NPC | **8** (각 호감 이벤트 3) | 위장 시스템의 상대역 |
| 이벤트 | 위장 코미디 12, 희귀 연출 파밍별 1+ | 변동성·웃음 담당 |
| 스토리 | 챕터 5 + 엔딩 2 + 진 엔딩 1, 메인 25h | 완주 60h+, 2회차 동기 |
| 도감 | 하숙부·손님 명부·조사 노트 3권 | 수집 층위 분리 (깊이/넓이/세계) |
| 업적 | 60 | 엔드게임 이정표 |

케이던스 검증: 이 표를 `unlocks.csv`(시간·조건별 해금 일정)로 전개하고, **시뮬레이터로 1년(4절기) 자동 플레이를 돌려 "새로움 없는 30분"이 없는지 기계적으로 검사**한다. 재미의 최소 조건을 사람 감이 아니라 데이터로 지킨다.

## 7. 재미 검증 게이트 (기간 게이트를 대체)

단계 전환은 날짜가 아니라 아래 테스트 통과로만 한다. 계측은 M5에서 만든 지표 킷(JSONL 로그)을 확장해 게임에 내장한다 — 어떤 동사에 시간을 쓰는지, 하루에 몇 가지 활동을 하는지 자동 수집.

| 단계 | 만드는 것 | 통과 기준 (테스터 5명 중 3명 이상) |
|---|---|---|
| **P1 「하루의 재미」** | 직접 조작 + 실시간 하루 + 텃밭·요리·채집 + 하숙 자동화 재정의 + 탐험지 1(동료 전투) | "오늘 할 일이 밀려서 즐거웠다"는 취지의 발화. 로그상 하루에 4개 이상 활동 혼합 |
| **P2 「한 절기의 재미」** | 절기 1개 + 동지 명절 + 낚시·부적 + 회색 시장 + 챕터 1 | 명절을 스스로 준비함(달력 확인 행동), 세션 후 "다음에 할 일" 3개 이상 말함 |
| **P3 「1년의 재미」= EA 시작선** | 4절기 순환 + 명절 2 + 지역 4 + 하숙생 10 + 자동화 전환 | 12시간 플레이 후 자발 재접속(재플레이율), 자동화 위임을 스스로 함 |
| **P4 「일생의 재미」= 1.0** | 6절 분량 전체 + 챕터 5 + 엔드게임 | 완주 테스터의 2회차 착수 의사, 도감 완성 시도율 |

P1이 실패하면 콘텐츠를 늘리지 않고 사슬 연결(원칙 3)과 케이던스(원칙 6)를 고친다 — 양이 아니라 구조가 원인이므로.
