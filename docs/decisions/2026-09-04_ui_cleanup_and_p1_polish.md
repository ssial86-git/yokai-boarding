# UI 정리와 P1 마감 손질 — 시계 카드·상태 칩·탭 메뉴·단축키 하나
날짜: 2026-09-04
결정:
- **유사 게임 관행을 따른 HUD 레이아웃.** 조사(스타듀밸리 HUD·모드 논의, Spirittea·Spiritfarer 리뷰)에서 얻은 원칙 셋: (1) 시계·날짜·날씨는 한 카드, 재화·상태는 작은 칩으로 한쪽에 모은다, (2) 체력 바는 구석, 알림은 왼쪽 아래 토스트, 상호작용 안내는 대상 가까이 또는 고정 알약, (3) 메뉴는 탭 하나에 모으고 "메뉴 열기 → 도구 → 확인" 같은 두세 단계를 만들지 않는다(Spirittea 가 "버튼 한 번이 더 든다" 는 비판을 받은 지점). 결과: 왼쪽 위 시계 카드(시각·시간대·일차 / 날씨·구역 / 진행 바), 오른쪽 위 칩 3개(돈·평판·침대) + "취침 [Z]"·"메뉴 [Tab]", 위 가운데 성주 영감 안내, 왼쪽 아래 체력 바와 그 위 토스트 로그, 오른쪽 아래 안내 알약(탐험지에서는 위에 Q/R/G 칩).
- **공용 테마는 코드로 만든다** (`UiStyles.make_theme`, `.tres` 테마 파일 없음 — CLAUDE.md 5.2). 색·글자 크기·여백은 tuning(`ui_*`). 패널은 불투명(`ui_panel_alpha=1.0`) — 반투명 뒤로 글자가 비치던 문제를 없앴다. 버튼·칩·진행 바·제목 글자가 한 결이다.
- **장부 메뉴(MenuHub)** 가 창고·하숙부·명부를 탭으로 묶는다. Tab 으로 열고 닫고, I/J/L 로 탭을 바로 연다. 창고 탭은 종류별 소제목 아래 "이름 ×n · 개당 값" — 상단 바의 창고 줄은 없앴다(길어지면 잘리던 문제의 근본 해결). LedgerPanel/RosterPanel 은 삭제.
- **배치 패널**은 제목 줄 + 카드 줄(가로 스크롤) + 드롭존 줄(휴식·텃밭·동행)이고 B 로 접힌다. 드롭존은 `mouse_filter=STOP`(Label 기본값 IGNORE 로 드롭이 빠져나가던 버그의 재발 방지 규칙).
- **P1 마감 손질**: 4일차부터 "부적을 만들려면 작업장이 필요합니다" 안내(hints.csv, 작업장을 지으면 사라짐), 부적 해금 문구에 작업장 명시. 이동 속도는 사용자가 올린 테스트값(140/240/110)을 그대로 두고 표기만 정리 — 정식값은 플레이 후 결정.

이유:
- 상단 바 한 줄에 모든 상태를 " · " 로 이어 붙이는 방식은 글자가 길어질수록 깨졌고(취침 버튼 실종), 창고 줄은 아이템 종류가 늘면 읽을 수 없었다. 카드·칩·탭 메뉴는 정보량이 늘어도 자리가 늘지 않는다.
- 단축키 하나 원칙: 취침(Z)·메뉴(Tab)·탭(I/J/L)·배치 접기(B)·부적(Q/R/G)·상호작용(E). 마우스로도 전부 가능하다.

대안과 기각 사유:
- 스타듀식 하단 도구 바(핫바): 이 게임은 도구를 '들지' 않는다(E 가 상황을 판단). 핫바는 불필요한 단계를 만든다.
- 대화창·심사 카드를 같은 ListMenu 로 통합: 이미 잘 동작하고 모달 성격이 달라 이번엔 테마만 공유했다.
- 안내 줄을 상단 바 안에 넣기: 바 높이가 안내 유무로 널뛰어 카메라 오프셋이 흔들렸다. 따로 두고 카드 줄 아래에 붙였다.

미해결·사용자 결정 필요:
- 글자 크기 13/15(뷰포트 기준, 창 2배에서 26/30px)와 팔레트 색 배치는 초안. 픽셀 폰트는 이전에 되돌린 이력이 있어 시스템 폰트 유지.
- 안내 줄이 잠긴 층 점선 위로 겹칠 수 있다(투명하지 않은 패널이라 읽기는 된다).
- 자리표시 그림(요괴·방·플레이어·적)은 그대로다 — docs/02 아트 트랙은 사용자 숙제.
