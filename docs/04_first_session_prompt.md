# 04. Claude Code 세션 프롬프트 v3 — P1 「하루의 재미」 재개발

전제: `yokai-boarding` 저장소에 M5까지의 코드가 있고, docs/ 에 00~08 최신본이 커밋되어 있다. CLAUDE.md는 v3(실시간 하루·플레이어 컨트롤러 반영)로 교체되어 있다.
P1은 한 세션이 아니라 **세션 4개(S1~S4)**로 나눈다. 각 세션 프롬프트를 순서대로 사용한다.

---

## P1-S1: 기반 전환 (시계·스키마·마이그레이션)

```
docs/08_master_design.md 와 docs/01_vertical_slice_scope.md(v3), CLAUDE.md 를 읽고 시작해라.
이 세션의 목표는 P1 기반 전환이다. 게임플레이 신규 기능은 만들지 마라.

1. 착수 전에 변경 계획(수정/신설 파일 목록)을 보여 주고 승인 후 진행해라.
2. Clock 을 페이즈 스테이트머신에서 실시간 하루(하루=실시간 12분, tuning.csv)로 교체해라.
   시간대(아침/낮/저녁/밤)는 조명·이벤트 트리거로만 남기고 강제 컷은 취침뿐이다.
   기존 페이즈 의존 코드(심사·사연 트리거)는 시간대 트리거로 이식해라.
3. P1 신설 스키마를 만들어라: materials, crops, fish, talismans, tools, regions, enemies,
   unlocks, chains, metrics_events (docs/01 v3 5절). build_resources.py 검증 확장 포함.
   chains.csv 는 용도 3칸 미달 시 빌드 실패하게 해라.
4. docs/01 v3 4절의 케이던스 표를 unlocks.csv 초안으로 옮겨라.
5. 세이브 v4→v5 마이그레이션(시계·플레이어 위치·탐험지 상태 자리)과 왕복 테스트.
6. Metrics autoload: metrics_events.csv 정의대로 JSONL 기록. 스모크 테스트에 지표 발생 검증 포함.
7. 전체 테스트 통과 로그를 보여 주고 관심사 단위 커밋. push 는 물어보고 해라.
```

## P1-S2: 플레이어와 집·마당·뒷산

```
P1-S1 완료 상태다. CLAUDE.md 9절 시작 루틴 후 진행해라.

1. src/player/: CharacterBody2D 이동(좌우·사다리·단차·문 통과), 달리기(스태미너), 
   상호작용 프롬프트("E: 캐기"). 수치는 전부 tuning.csv.
2. 하숙집 렌더를 '걸어다니는 집'으로: 방 그리드 로직은 그대로 두고 플레이어가 방 앞에서
   상호작용(배치 패널·증축·대화 호출)하게 바꿔라.
3. 마당(텃밭 6칸: 괭이질→파종→물주기→수확)과 뒷산(채집 포인트, 일일 리스폰) 씬을
   regions.csv 기반으로 조립해라. materials/crops 데이터는 docs/01 v3 3절 수량대로.
4. 요괴 배치 자동화 재정의: 배치된 요괴가 물주기·요리·청소를 자동 수행하되 효율 계수
   (tuning.csv, 기본 0.6)를 적용해라.
5. 이동감 수치는 기본값만 넣고 나에게 플레이 후 조정을 요청해라. 커밋하고 3줄 보고.
```

## P1-S3: 요리·낚시·부적

```
1. 조왕 부엌 가마솥: recipes.csv 티어 1~2, 실시간 조리, 산출물의 3중 용도
   (손님 만족 / 동료 버프 / 판매) 연결. chains.csv 3칸 검증 통과 필수.
2. 개울 낚시: 타이밍 바(관대한 판정), fish.csv 4어종+고물 2.
3. 부적 제작(talismans.csv 3종: 투척·채집·귀환)과 도구 Lv1~2 업그레이드.
4. 저녁 심사·밤 사연이 실시간 시간대에서 자연스럽게 뜨는지 통합 테스트.
```

## P1-S4: 잿빛 들 (탐험 + 동료 자동 전투)

```
1. 잿빛 들(낮): regions.csv 로 채집 8포인트 + 적 2종 + 미니보스 1 배치.
2. companions/: 동료 요괴 2 동행, 자동 교전(가까운 적) + 플레이어 반경 복귀.
   플레이어는 이동·회피·부적 투척(쿨다운)·후퇴. 편성은 아침 배치 UI에서.
3. 스태미너·귀환(부적)·전리품 → 제작/요리 사슬 연결.
4. tools/sim/ 에 14일 자동 플레이 시뮬레이터: 경제 곡선, 위임 손익 교차점(6~8일차 목표),
   unlocks.csv 케이던스 검사("처음 보는 것 없는 30분" 탐지).
5. P1 게이트 준비: 지표 리포트 스크립트(하루 활동 혼합 수), 플레이테스트 킷 갱신.
```
