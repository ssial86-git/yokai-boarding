```

# P2 「한 절기의 재미」 세션 프롬프트 (v4 추가, 2026-09-04)

전제: P1-S1~S4 완료(실시간 하루·플레이어·텃밭·채집·요리·낚시·부적·잿빛 들·시뮬레이터), UI 정리(시계 카드·상태 칩·장부 탭 메뉴) 반영. P2 게이트(docs/08 7절): 명절을 스스로 준비함(달력 확인 행동), 세션 후 "다음에 할 일" 3개 이상 발화. P2 도 세션 4개로 나눈다. 매 세션 CLAUDE.md 9절 루틴 → 테스트·창 모드 검사·독립 검증 에이전트 → ADR → 커밋·push·CI 확인.

## P2-S1: 절기 캘린더와 음기 날씨

```
1. 절기 캘린더: 4절기 × 28일 구조를 GameState/Clock 에 넣되 P2 는 봄 한 절기(28일) 순환까지. seasons.csv(절기 이름·길이·작물 계절 키), 세이브 v6(season, day_of_season, 음기 지수, 소절기 상태) + v5 마이그레이션·왕복 테스트.
2. 음기 지수 날씨: weather.csv 로 이승 날씨 × 음기(0~3) 추첨표를 정의한다. 음기 짙은 날(2 이상) = 이승 손님 가중치↓·마계 종족 가중치↑, 마계 작물 성장 가속(crops.yin_growth_bonus 연결), 잿빛 들 채집 풀에 음기 조건 재료 등장(materials.yin_condition 연결). 비 오는 날 = 음기 판정이던 임시 코드를 걷어낸다.
3. 소절기 이벤트 8 중 P2 범위 2개(장마 시작·만월)를 season_events.csv 로: 이틀짜리 미니 이벤트, 효과(날씨 고정·채집 배율·손님 가중치)는 데이터.
4. HUD 시계 카드에 절기·달력 날짜·음기 표시. 장부 메뉴에 '달력' 탭(28일 격자, 오늘·명절·소절기 표시). 달력 열람은 metrics(calendar_opened)로 기록 — P2 게이트 지표.
5. 통합 테스트: 28일 자동 진행(시간대 트리거·성장·이벤트), 음기 효과, 세이브 왕복. 자동 플레이 검사에 달력 탭 캡처 추가.
```

## P2-S2: 동지 명절과 목표 층위 3

```
1. festivals.csv: 동지(봄 절기 마지막 날에 배치 — P2 는 절기 1개이므로 '절기 끝 명절' 자리에 동지 규칙을 얹는다). 준비 목표(요리 n종·손님 초대 수·장식 아이템)·당일 진행·채점(만점 조건)·보상(평판·돈·희귀 손님)을 데이터로.
2. goals.csv: 목표 층위 3 — 오늘(부탁·재료·손님) / 절기(명절 준비·한정 작물·증축) / 장기(챕터·도감·정착). 진행 판정은 조건식(unlocks 와 같은 문법 확장), 장부 메뉴 '할 일' 탭 + HUD 요약 칩("할 일 2/5").
3. 명절 당일 연출은 최소(집 장식 토글·손님 몰림·채점 메시지). 절기가 끝나면 다음 절기로 넘어가며 달력이 리셋된다.
4. unlocks.csv 를 28일로 확장하고 시뮬레이터 30분 규칙을 통과시킨다.
```
