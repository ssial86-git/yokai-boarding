## P2-S1: 절기 캘린더와 음기 날씨

```
1. 절기 캘린더: 4절기 × 28일 구조를 GameState/Clock 에 넣되 P2 는 봄 한 절기(28일) 순환까지. seasons.csv(절기 이름·길이·작물 계절 키), 세이브 v6(season, day_of_season, 음기 지수, 소절기 상태) + v5 마이그레이션·왕복 테스트.
2. 음기 지수 날씨: weather.csv 로 이승 날씨 × 음기(0~3) 추첨표를 정의한다. 음기 짙은 날(2 이상) = 이승 손님 가중치↓·마계 종족 가중치↑, 마계 작물 성장 가속(crops.yin_growth_bonus 연결), 잿빛 들 채집 풀에 음기 조건 재료 등장(materials.yin_condition 연결). 비 오는 날 = 음기 판정이던 임시 코드를 걷어낸다.
3. 소절기 이벤트 8 중 P2 범위 2개(장마 시작·만월)를 season_events.csv 로: 이틀짜리 미니 이벤트, 효과(날씨 고정·채집 배율·손님 가중치)는 데이터.
4. HUD 시계 카드에 절기·달력 날짜·음기 표시. 장부 메뉴에 '달력' 탭(28일 격자, 오늘·명절·소절기 표시). 달력 열람은 metrics(calendar_opened)로 기록 — P2 게이트 지표.
5. 통합 테스트: 28일 자동 진행(시간대 트리거·성장·이벤트), 음기 효과, 세이브 왕복. 자동 플레이 검사에 달력 탭 캡처 추가.
```
